# Drafts

Scratchpad for in-flight soundness work. Files here are **never
imported** by the public modules under `AeneasSoundness/{LLBCSharpPaper,
Concretise,Soundness}/` and may contain `sorry`. G6 (no-`sorry` in
`Soundness/`) explicitly exempts this directory.

The directory exists so per-phase agents have a stable place to
sketch a proof, leave failed attempts, or land work that needs a
follow-up commit to integrate. Anything here that survives a phase
boundary should either move into the public tree or be deleted.
